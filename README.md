# 🖼️ SVSV PhotoShop Editor

A lightning-fast, zero-cost photo editing suite built entirely in the browser, giving creators professional-grade tools without the paywall.

## Features

### Basic Adjustments
- ☀️ **Brightness** - Adjust image brightness from 0-200%
- ◐ **Contrast** - Control image contrast
- 🎨 **Saturation** - Modify color saturation
- 🌈 **Hue** - Shift color hues
- 👻 **Opacity** - Control image transparency

### Color Adjustments
- ⚫ **Grayscale** - Convert to black and white
- 🟫 **Sepia** - Apply vintage sepia tone
- ⬜ **Invert** - Invert all colors
- 💨 **Blur** - Apply blur effect with adjustable intensity

### Transform Tools
- 🔄 **Rotate** - Rotate image 90 degrees
- ↔️ **Flip Horizontal** - Mirror image horizontally
- ↕️ **Flip Vertical** - Mirror image vertically
- ✂️ **Crop** - Crop 20% from all sides

### Effect Tools
- 🔍 **Sharpen** - Enhance image sharpness
- ▲ **Emboss** - Create 3D emboss effect
- 📍 **Edge Detect** - Highlight edges
- ⬜⬜ **Pixelate** - Create pixelated effect

### Filter Effects
- 📷 **Vintage** - Apply vintage filter
- 🔥 **Warm** - Add warm tones
- ❄️ **Cool** - Add cool blue tones

### Editing Functions
- 📁 **Upload Image** - Load images from your computer
- 💾 **Download** - Save edited images as PNG
- 🔄 **Reset** - Restore original image
- ↶ **Undo** - Undo last edit
- ↷ **Redo** - Redo previous edit

## How to Use

1. Click the **Upload Image** button to select a photo from your device
2. Choose any editing tool from the left sidebar
3. Adjust the slider (if available) to fine-tune the effect
4. Use Undo/Redo to navigate through your edits
5. Click **Download** to save your edited image
6. Click **Reset** to start over with the original image

## Technologies Used

- **HTML5** - Structure and Canvas API
- **CSS3** - Styling with gradient backgrounds and responsive design
- **JavaScript (Vanilla)** - All editing logic without external dependencies
